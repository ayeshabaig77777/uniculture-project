Manage Events

Add, edit, or delete events shown on the Events page — no code changes needed.

Manage Heritage Sites

Add, edit, or delete heritage sites shown on the Heritage page — no code changes needed.

Users

Ban or unban accounts — takes effect the next time that user logs in.

Cultural Map — Region Data

One-time setup: creates the 5 province/region documents used by the Cultural Map page. Safe to click again — it just overwrites with the same defaults.

Festivals & Events

One-time setup: creates the 15 event documents used by the Events page. Safe to click again — it just overwrites with the same defaults.

Tourism — Destinations

One-time setup: creates the 30 destination documents used by the Tourism page, the destination detail pages and the AI Trip Planner. Safe to click again — it just overwrites with the same defaults.

Culture — Places & Traditions

Creates the "Culture of …" content shown on tourism destination pages (food, weddings, dress, language, festivals, crafts, etiquette). Seed Culture only adds areas that do not exist yet. Replace all overwrites everything with the text in the code.

Languages — Learning Content

Adds the expanded "Learn This Language" vocabulary data (greetings, numbers up to 20, common words across 6 categories, phrases) to all 12 language documents in the languages collection. Safe to click again — only updates the language_learning field, existing language info is untouched.

Languages — Language Family

Adds the "Language Family" quick-fact (e.g. Indo-European > Indo-Iranian > Indo-Aryan) to all 12 language documents in the languages collection, replacing the "Coming Soon" placeholder on each language detail page. Safe to click again — only updates the language_family field, existing language info is untouched.

Heritage — Fix Missing Detail Content

Fills in the Historical Background, Cultural Significance, Opening Hours, Best Time To Visit and Did You Know fields for every heritage site that is missing them, using accurate content for well-known sites and a sensible fallback for others. Safe to click again — it only fills fields that are currently empty, existing content is never overwritten.
